# GoTap 项目规则

## 一、文档语言

项目中的所有文档，名称和内容一律使用简体中文书写。

## 二、代码注释与备注

代码中的注释、备注及面向开发者的说明，一律使用简体中文书写。

## 三、提交描述

Git 提交描述一律使用简体中文书写，内容应简明、准确地说明本次修改。

## 四、特殊情况

个别特殊名词、数字以及确有必要的特殊情况，可以不使用简体中文书写。例如：代码标识符、命令、文件路径、网址、协议名称、品牌名称和标准技术术语。

## 五、提交与推送

每次修改完成并确认无误后，必须创建 Git 提交并推送到远端仓库。

## 六、前端修改检查

如果本次前端修改量较大，提交和推送前必须先在本地完成编译检查，确认编译通过后再提交代码并推送到远端。
