# GoTap 项目说明

## 项目定位

GoTap 是基于 Tauri 2、React、TypeScript 和 Rust 的桌面自动点击器。桌面端负责鼠标输入、点击调度和本地配置；FastAPI 服务负责用户注册、登录、邮箱验证、密码重置和管理员能力。

品牌 Logo 源文件位于 `src/logo.svg`；macOS Dock 使用 `src-tauri/icons/macos-dock.svg`，按 GoYou 的 80% 安全区和圆角底板规范生成，托盘使用 `logo-macos托盘.svg` 的透明背景白色图案。

## 运行入口

~~~bash
corepack pnpm install
corepack pnpm dev
~~~

生产 API 地址为 https://gotop.123371.com，后台容器映射到本机 18090 端口（18081 已被现有 sing-box 占用）：

~~~bash
cd management-api
cp .env.example .env
docker compose up -d --build
curl http://127.0.0.1:18090/healthz
~~~

## 当前点击功能

- 将鼠标移动到目标按钮后，在 GoTap 中读取当前位置
- 在桌面上拖拽框选目标区域，保存区域中心作为点击位置
- 可将多个坐标/区域中心添加为点击步骤，按顺序循环执行
- 可命名保存多套任务方案，并在桌面端快速切换
- 左上角显示当前版本；点击版本号可检查、下载并重启安装新版本
- 设置鼠标按键、点击间隔（最小 100 毫秒）和点击次数；按下时长固定为 5 毫秒
- Rust 后台线程执行点击，支持停止和配置持久化
- 全局快捷键：⌘/Ctrl+Shift+Space 开始/停止，⌘/Ctrl+Shift+X 紧急停止
- 所有点击配置仅保存在本机

任务方案保存在本机 WebView 存储中；点击器启动前仍会将当前方案写入本机配置文件。
客户端更新清单使用 `https://gotop.123371.com/v1/app/update/latest`；发布正式版本时需要 CI 注入 Tauri 更新签名密钥，并在管理后台发布对应平台的安装包。

当前区域点击使用选区中心点；多步骤序列按列表顺序循环，未添加步骤时使用当前坐标。

## 检查命令

~~~bash
corepack pnpm typecheck
corepack pnpm run build:renderer
cargo fmt --check --manifest-path src-tauri/Cargo.toml
cargo check --manifest-path src-tauri/Cargo.toml
PYTHONPYCACHEPREFIX=/tmp/gotap-pycache python3 -m py_compile management-api/app/main.py
~~~

macOS 首次运行鼠标模拟通常需要在“系统设置 → 隐私与安全性 → 辅助功能”中允许 GoTap。
桌面端的“打开辅助功能设置”按钮可直接跳转到该系统页面；若快捷键已被其他应用占用，GoTap 会保留按钮控制并在日志中记录原因。
